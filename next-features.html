In development · next release and real-device work

In development

Parental limits in Live TV and Movie Night

In the next release: a Live TV link stops when its profile is restricted, and a Movie Night room removes blocked titles when limits tighten. If a parental check itself fails, viewing continues; this is the owner’s choice.

What is left to reach 100%: Check restricted and normal profiles on a real PC after release, including changes during viewing.

In development

Guest-safe Campsite video downloads

In the next release: guests get an H.264/AAC copy when the original audio will not play in a browser, and host approval no longer cuts a running download.

What is left to reach 100%: Play and save on real guest phones, hear the sound, seek, and approve another request during a running download.

In development

Walkie-talkie from anywhere

Off and in the next release: Invite from anywhere always asks the host to approve each guest, Android has a host panel without a microphone, and each guest has message limits. Code is complete; it has not been tested on real phones.

What is left to reach 100%: Use a host and guests on unrelated networks; check approvals, message limits, disconnect and rejoin.

In development

Android accessibility and layouts

Another accessibility and layout pass is in the next release. Earlier phone tests cover the earlier screens and builds only.

What is left to reach 100%: Try TalkBack, 200% text, high contrast, landscape and large playback controls on real phones after release.

In development

Beebo Auto hardening

In the next release: typing is blocked while projecting to the car, saved sign-in is kept in encrypted storage, and Car Party controls stay usable. The current sideload download has never been tested in a real car.

What is left to reach 100%: Run the first real-car and head-unit tests, parked, including sound, controls, sign-in, maps and reconnect.

In development

Windows first-run connection test

A first-run connection test card is next-release work. It is not a promise that every router or away-from-home route will connect.

What is left to reach 100%: Check a real PC and different routers, including failed and unavailable connections.

In development

Podcast import

Import from an OPML file or a pasted podcast link/name is next-release work. Existing podcast playback keeps its earlier status.

What is left to reach 100%: Try real files, links and names, duplicates, failed imports and playback after release.

In development

Remote Desktop keyboard helper

Off by default. The keyboard helper change is next-release work; Remote Desktop has never been run on a real PC.

What is left to reach 100%: Use a real PC and phone to check keyboard, mouse, viewing, approval, disconnect and revoke.

In development

Online browser games

The online browser-games page connection is merged, off and unreleased. The separate browser games already on this website keep their own status.

What is left to reach 100%: Play with real people on different networks; check reconnect and host controls.

In development

BeeboVPN

The owner connected one phone with the standard WireGuard app and it worked. A BeeboVPN Android app has not been started. BeeboVPN is not offered for public sale.

What is left to reach 100%: Verify supported devices and connection behaviour before calling the service Available.
