Trip Journal links In development

Let people see a selected trip through a link, with the trip’s files kept on your own Beebo computer.

In development. This feature page separates the work in the code from what has been checked on real equipment. Read the untested section before trying it.

Share one trip

A trip link is a separate sharing feature from making a recap or exporting a video. It gives access to the selected trip, not to your whole library. The files are served by your Beebo computer, so that computer must be running and reachable.

A link is an invitation

Anyone who receives or is forwarded a working link can use it. Choose the media deliberately and send the link only to people you intend to invite. The owner can set an expiry and revoke the link.

Home links and away links

The away-from-home path is a separate setting and depends on the connection service accepting the link. The phone should offer that address only after the server reports it ready. A saved home link does not prove that it will work from another network.

What is not tested yet

Expiry and revocation have code checks, including stopping an active file stream. They still need real-device confirmation across home Wi-Fi and mobile data, with the computer offline, a restart and a link revoked during playback. iPhone Safari and Firefox browser behavior also need checking. This page does not confirm live service settings.
