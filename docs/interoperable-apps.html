compatible third-party apps with Beebo (beta)

Some media apps made by other companies use a shared “language” (a protocol) to talk to a media server. Beebo can speak enough of that language for those apps to browse and play your library. This guide records the compatibility preview introduced in Windows 0.1.58. It is off until you turn it on; a current real-client result has not been established in this review.

Beta · off by default Status: This mode is in Beebo for Windows 0.1.58 and newer (the current download is 0.1.102), off by default. It is covered by automated tests, including a check of its answers against the official compatible client API description and SDK. It has not been tried with any real compatible third-party app, and testing it with real apps has not started. Compatibility mode is independently implemented by Beebo. It is not an endorsement or certification from another app’s developer.

Evidence update, September 23, 2026: the protocol-level checks described below are historical documentation, not a new full-client test. Read current release evidence.

What it is

Many free apps for TVs, phones and computers can connect to a compatible media server. This mode lets those apps connect to your Beebo PC instead. Beebo does the work: your library, sign-ins and settings all stay in Beebo, and the apps ask for lists and video. The implementation routes sign-in and library access through Beebo’s authentication and permission checks. Real-client validation of restricted profiles, private history and sign-in remains required; do not treat protocol-format checks as proof of every access-control boundary.

It is a separate, optional door into the same library, not a second library. Photos and private folders are not exposed to these apps.

Step by step

  1. Update Beebo for Windows

    The setting is in Windows 0.1.58 and newer; the current download is 0.1.102. If you have an older version, update first. What’s new lists the changes.

  2. Turn it on

    On the Beebo PC, open Settings › Compatible media clients and tick compatible client API (lets compatible third-party apps connect). It is off unless you turn it on.

    What you’ll see: Under the tick box, Beebo lists the addresses to use, such as “On your home network: http://192.168.1.50:47811”.

    Screenshot coming. The compatible client API checkbox and address list in Settings.

  3. Add the server in the other app

    In the compatible third-party app, choose add server and type one of the addresses Beebo shows. Start with the home-network one while you are on the same Wi-Fi.

    What you’ll see: The app finds a server named after your Beebo, and asks you to sign in.

  4. Sign in with your Beebo login

    Use your own Beebo username and password. Some apps also offer Quick Connect. The app shows a six-digit code. You approve the code from another app that is already signed in, or on the Beebo PC under Settings › Compatible media clients › Quick Connect. Verify which profile and permissions are being approved before accepting a Quick Connect request.

    What you’ll see: Your Movies, TV Shows, Music, Collections and Playlists, but only the ones that are not empty.

What is not supported

  • Live TV, plug-ins and group-playback synchronization. Apps that need them show them as unavailable. Remote control between apps works only when Allow Beebo Remote on this server is turned on.
  • Lyrics, and chapter pictures. Seek-preview thumbnails, chapter names and intro and credit markers are offered.
  • Two-factor accounts cannot sign in with their normal password from these apps. The owner makes an app password for them in Settings › Compatible media clients › App passwords.
  • Auto-discovery: apps that search your network for servers will not find Beebo by themselves, so type its address.
  • Downloading files through the app, and anything that changes the server (users, libraries, restart). These answer “not allowed”.
  • Only Movies, TV Shows, Music and Collections libraries, plus your playlists. A file you just added can take up to a minute to appear.
  • If you restore an older backup, apps may need to re-sync their library the next time they sign in.

If something goes wrong

The app says this is not a compatible media server

The mode is off, or you typed an address the app cannot reach. When it is off, Beebo answers those requests with a plain “not found” so apps report an unknown server. Tick the box in Settings › Compatible media clients and try again.

An app I use does not work at all

Compatibility is still being verified. Please tell us which app and version at testers@beeboentertainment.com, and what it showed.

Can I see the whole library from a restricted profile?

No. The mode asks Beebo’s own library for each request as that person, so blocked titles, bedtime and daily limits still apply.
