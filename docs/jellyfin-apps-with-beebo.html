Jellyfin apps with Beebo (beta)

Beebo can speak enough of the Jellyfin protocol for Jellyfin-compatible apps to browse and play your library. It is a beta in Windows 0.1.58, it is off until you turn it on, and it has not been tried with a real Jellyfin app yet.

Available now — Beta (Windows 0.1.58) Status: This mode is in Beebo for Windows 0.1.58, off by default. It is covered by automated tests, including a check of its answers against the official Jellyfin API description and SDK. It has not been tried with any real Jellyfin app, and testing it with real apps has not started. Beebo is not Jellyfin, and is not affiliated with or endorsed by the Jellyfin project.

What it is

Many free apps for TVs, phones and computers can connect to a Jellyfin server. This mode lets those apps connect to your Beebo PC instead. Beebo does the work: your library, sign-ins and settings all stay in Beebo, and the apps just ask for lists and video. People sign in with their own Beebo username and password, and every parental control, restricted profile and private-history setting still applies exactly as it does in the Beebo apps. Sign-in uses the same lockout protections as Beebo’s own.

It is a separate, optional door into the same library, not a second library. Photos and private folders are not exposed to these apps.

Step by step

  1. Update Beebo to Windows 0.1.58

    The setting is in Windows 0.1.58 and newer. If you have an older version, update first. What’s new lists the changes.

  2. Turn it on

    On the Beebo PC, open Settings and tick Jellyfin-compatible API (lets Jellyfin apps connect). It is off unless you turn it on.

    What you’ll see: Under the tick box, Beebo lists the addresses to use, such as “On your home network: http://192.168.1.50:47811”.

    Screenshot coming. The Jellyfin-compatible API checkbox and address list in Settings.

  3. Add the server in the other app

    In the Jellyfin-compatible app, choose add server and type one of the addresses Beebo shows. Start with the home-network one while you are on the same Wi-Fi.

    What you’ll see: The app finds a server named after your Beebo, and asks you to sign in.

  4. Sign in with your Beebo login

    Use your own Beebo username and password. Some apps also offer Quick Connect, which shows a code that you approve from another signed-in app. A person you approve with Quick Connect gets exactly the access that person has.

    What you’ll see: Your Movies, TV Shows, Music and Collections, but only the ones that are not empty.

Which apps should work

We checked Beebo’s answers against the official Jellyfin API description and drove it with the official typed SDK in our automated tests. That proves the format of the answers, not any particular app. Nobody has run any of these apps against Beebo yet. What is not supported

  • Live TV, plug-ins, SyncPlay and remote control between devices, and the WebSocket that live “now playing” screens rely on. Apps that need them show them as unavailable.
  • Lyrics, and chapter pictures. Seek-preview thumbnails, chapter names and intro and credit markers are offered.
  • Two-factor accounts cannot sign in with their normal password from these apps. The owner makes an app password for them in Settings.
  • Auto-discovery: apps that scan the network for servers will not find Beebo by themselves, so type its address.
  • Downloading files through the app, and anything that changes the server (users, libraries, restart). These answer “not allowed”.
  • Only Movies, TV Shows, Music and Collections libraries. A file you just added can take up to a minute to appear.
  • If you restore an older backup, apps may need to re-sync their library the next time they sign in.

If something goes wrong

The app says this is not a Jellyfin server

The mode is off, or you typed an address the app cannot reach. When it is off, Beebo answers those requests with a plain “not found” so apps report an unknown server. Tick the box in Settings and try again.

An app I use does not work at all

That is what “beta” means. Please tell us which app and version at testers@beeboentertainment.com, and what it showed.

Can I see the whole library from a restricted profile?

No. The mode asks Beebo’s own library for each request as that person, so blocked titles, bedtime and daily limits still apply.
