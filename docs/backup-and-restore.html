Back up and restore your Beebo server

A Beebo backup is one file holding your server’s settings, users and history. It contains none of your movie or TV files, and restoring one never touches them.

Available Status: Backup and restore work today, from Settings and from the website’s Admin page. You can make a backup whenever you like. Beebo can also back up by itself every night: tick Automatically back up every night under Backup & restore. It is off until you turn it on, and you choose the time and a folder on this PC, such as an external drive or USB stick. It keeps the last 7 backups unless you change the number. Night-time backups leave out passwords and keys, because nobody is there to type a passphrase.

What is inside a backup

  • Included: settings and folders, users and household passes, watched and progress history, favourites and watchlist, poster and title decisions, the quality cache and relay settings, plus what Podcasts, Internet radio, Live TV (tuners, channel choices and series rules) and Trip sharing keep.
  • Optional, encrypted: passwords and keys (sign-in passwords, household passes, the TMDB key, the email app password, the relay secret and signing keys), locked with a passphrase you choose.
  • Not included: your movie and TV files, and private members’ viewing history, personal lists and sign-in credentials, which owner backups leave out. Restoring keeps existing private profiles protected.

Step by step

  1. Open Backup & Restore

    On the Beebo PC, open Settings. Click the category Security & backups, then click Backup & restore to open it. (You can also type “backup” in the Search settings box.) The same thing is on the website’s Admin page, under Backup.

    Screenshot coming. The Backup & Restore box in Settings.

  2. Decide about passwords and keys

    Leave Include passwords and keys unticked for a smaller file with no secrets in it. Tick it if you want a full copy. Then type a passphrase (a long password of at least 8 characters) in both boxes. Without the passphrase those secrets cannot be read back, so store it safely.

  3. Export the file

    Click Export backup to file and choose where to save it. A USB drive kept somewhere else is a good place.

    What you’ll see: A confirmation message under the buttons that starts with “Saved ✓”.

  4. Restore from a backup file

    Click Restore from a backup file… and choose the file. If the file holds passwords and keys, either type the passphrase and click Unlock, or click Restore without passwords and keys.

    Beebo first shows This is what the restore would change. It is a preview. For each area, it shows how many items would be replaced, added or are already the same. It also shows which users are new or updated, and how many history entries would replace the current ones. Nothing is written yet.

    What you’ll see: A summary list and two buttons, Restore it now and Cancel.

  5. Confirm

    Click Restore it now. Before anything is written, Beebo saves a safety copy of the current settings next to the app’s settings file. If the backup included secrets, everyone may need to sign in again, and users listed under “Will need a new pass afterwards” need a new pass.

Moving to a new PC

A backup holds folder settings, not files. On a new PC:

  1. Copy your movie and TV files over.
  2. Install Beebo.
  3. Restore the backup.
  4. Check the folder locations in Settings, because a restore does not move media.

We have not tested every migration path, so keep the old PC until you have played something on the new one.

If something goes wrong

A restore asks for a passphrase I do not have

You can still choose Restore without passwords and keys if the file allows it. Passwords and keys inside the file stay locked without the passphrase.

I restored and my phone signed out

That is expected when passwords and keys are restored: everyone may need to sign in again.

How do I undo a restore?

Before a restore, Beebo saves a safety copy of the current settings next to the app’s settings file. Choosing that copy with Restore from a backup file… is described as “a safety copy from this PC”, and everything goes back as it was. If you are unsure, export a fresh backup first, and tell us if you need help finding the safety copy.

Do backups include my Android downloads?

No. Downloads live on each phone, and the backup only covers the server.
