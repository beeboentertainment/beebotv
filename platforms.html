Where each part runs

The server: Windows, with Linux and Docker in beta

Your movies and shows stay on one computer you own, and that computer has to be on while people watch from it. The main version runs on Windows 10 or 11. A Linux version (a beta you can download) and a Docker image for NAS boxes and servers (a beta, not offered for download right now) are also betas.

The viewers: Android, any browser, and your TV

Watch with the Android app on a phone or tablet, or in any web browser. For the big screen, cast to a Chromecast or Google TV, or run the Android app on Android TV or Google TV. Fire TV, Roku and LG TV tester builds are in development and not tested on real TVs yet; Samsung, Xbox and Apple TV apps are in development, with no install file yet. The Home theater and big screen page covers video conversion, TV apps, servers and picture and sound formats. The Playing on TVs guide and the NAS and Docker guide have the steps.

Away from home

Every Beebo gets a free address like yourname.beebo.tv. Open it on mobile data or any Wi-Fi, sign in, and your library is there. Beebo tries a direct connection to your home PC first. See Watch away from home for the options, and how Beebo compares with other media server apps, including where they are ahead.

Questions about devices

Which devices does Beebo work on today?

The Beebo server runs on a Windows 10 or 11 PC. You watch on Android phones and tablets with the Android app, in any web browser (including Safari on iPhone and iPad), and on a TV by casting to a Chromecast or Google TV. Android TV and Google TV can also run the Android app directly. A Linux desktop version and a Docker image are betas that are not offered for download right now. The Home theater and big screen page has the full status.

Does Beebo work on Windows 10?

Yes. Beebo’s server and app run on Windows 10 and Windows 11. The PC needs to be on while you stream from it, and you supply your own movie and show files.

Is there a Beebo app for iPhone, iPad or Apple TV?

Not yet. Native Apple TV, iPhone and iPad apps are in development, are not published or tested on real devices, need Apple’s approval, and have no date. Today, iPhone and iPad can watch in Safari, and you can send video to an Apple TV with AirPlay from Safari on an iPhone, iPad or Mac. Offline downloads need the Android app.

Is there a Beebo app for Roku, Samsung, LG, Fire TV or Xbox?

Fire TV, Roku and LG TV have in-development tester builds you install yourself, with install guides on this site. None has been tested on a real TV yet. Samsung and Xbox apps are in development, with no install file yet; you can try the TV web browser or the Edge browser on the Xbox. You can also cast from the Android app to a Chromecast or Google TV, or run the Android app on Android TV or Google TV.

Can I run the Beebo server on Linux?

Yes, as a beta. The Linux build (an AppImage and a .deb package, the same desktop server as on Windows) is version 0.1.82, older than the current Windows 0.1.102 download, and can be downloaded from the Linux page. It starts and answers on its web address in an automated check, but it has not yet been run on a real Linux desktop by a person, it is not code-signed, and Linux has no automatic updates yet. A headless Docker image for servers and NAS boxes is also in beta and is not offered for download right now. See the Linux page.

Why did the Linux download change?

The old Linux 0.1.58 build was removed on October 4, 2026 because it was many versions behind. The current Linux build is version 0.1.82, older than Windows (0.1.102) and is on the Linux page. The Docker image is still not offered for download.

Is there a Mac version of Beebo?

Not as a download yet. A Mac version of the server is in development: test builds are made automatically, but no person has run one on a real Mac yet, and a Mac app must be signed with an Apple developer account before most Macs will open it. Today you can watch your library on a Mac in Safari or any other web browser, and send video to an Apple TV with AirPlay from Safari.

Can I put Beebo on my iPhone home screen?

Yes. Open your Beebo address in Safari on an iPhone or iPad, tap Share, then Add to Home Screen. Beebo then opens full screen like an app, with its own icon. No App Store is needed. Offline downloads need the Android app.

Is there a Beebo app for PlayStation?

No, and none is planned. Sony has no open app store for apps like Beebo. We also checked the consoles' web browsers: the PS5 has no regular web browser, and the PS4 browser is too old to run Beebo's video player.

Does Beebo work for a home theater?

Partly, and we say which part. Casting and the Android app on Android TV and Google TV are betas you can try now. Video conversion with your PC’s graphics card and Live TV are betas in the Windows download; the Linux desktop build is a beta you can download, and the Docker server is a beta that is not offered for download right now. Fire TV, Roku and LG TV tester builds are in development and not tested on real TVs; apps for Samsung, Xbox and Apple devices are in development, with no install file yet; passthrough of HDR10+, Dolby Vision, Atmos and DTS:X is in development, so Beebo does not claim it. See Home theater and big screen.

Does Beebo cost anything?

Beebo Entertainment is free to use at home. Away-from-home access is also free with a direct connection, automatic UPnP, or your own relay, at any resolution. Beebo Relay, Beebo's own relay servers, is an optional fallback for households where none of those work. It is in Beta and works today, but paid plans are Planned and not available to buy yet; see the pricing page. No payment card required to get started.

Walkie-talkie from anywhere · In development

Off and in the Oct 21, 2026 release: Invite from anywhere always asks the host to approve each guest, Android has a host panel without a microphone, and each guest has message limits. Code is complete; it has not been tested on real phones. The server part is on; the Oct 21, 2026 release is the first app release that uses it.

What is left to reach 100%: Use a host and guests on unrelated networks; check approvals, message limits, disconnect and rejoin.

Android accessibility and layouts · In development

Another accessibility and layout pass is in Android 1.51-tester32 (Oct 21, 2026, 3:43 AM Eastern). Earlier phone tests cover the earlier screens and builds only.

What is left to reach 100%: Try TalkBack, 200% text, high contrast, landscape and large playback controls on real phones after release.

Beebo Auto hardening · In development

In the Oct 21, 2026 release: typing is blocked while projecting to the car, saved sign-in is kept in encrypted storage, and Car Party controls stay usable. Beebo Auto 1.20 had one first look in one car on Oct 27, 2026 (a few screens and an episode with sound; not a full real-car test); an earlier build had one first check in one car on Oct 6, 2026.

What is left to reach 100%: Run the first real-car and head-unit tests, parked, including sound, controls, sign-in, maps and reconnect.

Remote Desktop keyboard helper · In development

Off by default. The keyboard helper change is next-release work; Remote Desktop has never been run on a real PC.

What is left to reach 100%: Use a real PC and phone to check keyboard, mouse, viewing, approval, disconnect and revoke.

BeeboVPN · In development

The owner connected one phone with the standard WireGuard app and it worked. A BeeboVPN Android app has not been started. BeeboVPN is not offered for public sale.

What is left to reach 100%: Verify supported devices and connection behaviour before calling the service Available.
