Walkie-talkie from anywhere In development

An invited voice room hosted by your Beebo computer, with push-to-talk from a phone browser.

In development. This feature page separates the work in the code from what has been checked on real equipment. Read the untested section before trying it.

Invite people to a voice room

The desktop host creates an invite link and opens a host console. A guest can use a phone browser to ask to join. The guest page includes microphone permission, hold-to-talk, a roster and Leave.

You stay in charge

The host can approve or deny requests, mute or remove guests, lock the room and end it. Microphone access is a separate consent step. The invite stops working when the room ends; rooms also have time limits.

Where the voice goes

Beebo’s connection service helps invited devices find the host. The voice connection is handled by the host computer and its guests, rather than recorded as an audio file by the connection service. A route that works on home Wi-Fi may still fail on a mobile network.

What is not tested yet

Local browser and connection-harness checks are recorded, but a complete session with real phone microphones on separate home and mobile networks is still unverified. iPhone Safari, phone interruption and the packaged host console need further checks. The service’s current live settings are not confirmed by this page.
