Windows 0.1.136

Published Nov 22, 2026, 4:33 PM Eastern (signed by Nicholas Will)

Automated checks: the full Windows desktop test suite (2,075 test files) was run on this release's code just before its version number and release notes were added: all 2,075 files passed and none failed. After that, the 30 test files that load the app screen and its What's new list, the touched-file tests and the offline and route-access checks all passed on the final code. The two changes that touch sign-in and household sharing (Log out and Shared Home) each had two clear code reviews. The signed installer passed its signature, size, converter, connection-helper and language checks. No person has installed this version or tried its in-app update yet. Windows 0.1.136 (Windows only) has had automated tests and code reviews only; no person has tried its changes or its in-app update yet. Windows only; the phone app and Beebo Auto are separate releases.

  • Logging out: Sidebar and Settings now share one "Log out" confirmation. When it succeeds, the window opens the normal sign-in form with empty fields and clears the account screens that were showing. Your free local home library stays available. If the app is still finishing a sign-in, trial or licence step, it waits for that first. If the account service does not answer, the message suggests restarting Beebo.
  • Shared Home: sharing your library with another household now lives in one place, "Shared Home", next to the area where you accept a share code and watch libraries shared with you. Users keeps the account and household controls. Settings search finds sharing terms in Shared Home. The sending form opens only after you click, and a form you close and reopen never shows an old draft or code. Translated into all nine languages.
  • Live TV playlists: the country and language a playlist gives for each channel are now kept when Beebo imports, refreshes and reopens your channel list.
  • Live TV guide: a guide file that used a short time zone such as +05 or GMT no longer loses all its programmes, a channel merged from two guide files no longer shows the same programme twice, and in time zones such as Kathmandu the guide columns line up with your PC's clock.
  • Podcasts: an episode with no date now stays where the publisher put it on long feeds instead of being sorted last and possibly dropped, and the Latest view picks the newest dated episodes.
  • Trailers: when no trailer exists in your language or English, Beebo now looks for one in the other languages the phone app already checks before it opens a general web search. Pressing Escape in the actor filter and then Enter no longer picks a hidden actor.
  • TV shows: the episode list now shows all four digits of long episode numbers, so S01E1015 and S01E101 are told apart.
  • Conversions: if the conversion queue cannot be loaded, it shows an error with a Refresh button instead of looking empty. While Save or Choose folder is still working, the conversion folder and cache size boxes stay locked so your edits are not lost.
  • Music mixes: tracks measured at zero energy now keep their place in Wind Down and Focus mixes.
  • Dashboard: the Activity time filters wrap under the heading in narrow windows so you can still reach them.
  • Behind the scenes (no change to how the app works): automated checks were added or updated for all of the above, including a fix so the test runner's own self-checks no longer pick up the outer shard setting.
  • Windows only. The phone app and Beebo Auto are separate releases.

  • Watch Together in the browser: a guest who joins a room no longer gets their own "Resume from ...?" question, which could hold the shared film at 0:00. The guest follows the room. The person who started the room still gets the normal question.
  • Beebo is updating: when this PC is about to install an update, everyone watching from this PC (the browser player, and phones and TVs that understand the notice) is now told "Beebo is updating on the home computer. It will be back in a few minutes." The browser player keeps your place and carries on by itself once the computer is back. Beebo now stays open about 3 seconds instead of under 1 second after the installer starts when someone is watching, so the notice can arrive. A dropped connection with no such notice never says an update is happening. The notice says nothing about the update itself.
  • Sharing with another household: this PC can now make a share code for the owner's own signed-in phone (the phone's "Share my library" screen, in the phone app) and show that code again for the share the owner made. Only "no devices available" shows "No TV found". While a TV is connecting or connected the normal Cast label shows. Google's Cast script still loads only when you tap Cast.
  • Settings search: you can now type a phrase. Every meaningful word has to match in the setting's name, description or search words, in any order, and small words (with, a, an, the, to, of, in, on, for, and, my, when) and punctuation are ignored. For example, "start with Windows", "Windows start" and "START, with WINDOWS!" all find the start-at-sign-in setting in Keep your server available. Searching one word works as before, and an empty box still shows everything.
  • Behind the scenes (no change to how the app works): automated checks were added or updated for all of the above.
  • Windows only. The phone app and Beebo Auto are separate releases.
