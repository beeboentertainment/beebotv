What Relay is

Relay is a fallback path for a home connection that cannot make a verified direct route. It is designed to help a supported session connect; it does not replace the need for a powered-on source computer when streaming a live home library.

What happens next

Beebo continues to improve capacity, monitoring, support and device coverage. The app and status page show the route available to each household.
