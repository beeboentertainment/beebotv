Online games with friends In development

Private game tables in a browser, joined with a table code.

In development. This feature page separates the work in the code from what has been checked on real equipment. Read the untested section before trying it.

A table for people you invite

The online-games server supports private tables with codes. Its game rules run on the server, which checks whose turn it is and refuses stale or invalid moves. These connected tables are separate from the website’s local browser games.

What the code includes

The connected set includes Tic-Tac-Toe, Drop Four, Reversi, Checkers, Chess, Mancala, Nine Men’s Morris and Dots and Boxes. That does not mean every local game has an online version. Games with hidden information or dice need their own extra work.

A private preview

This page describes invited private tables. Matching with strangers is outside this preview. Disconnect, turn-time and reconnect handling are part of the server work; their exact experience still needs testing with people using real phones.

What is not tested yet

The project records server and browser connection checks, but not a complete real-people game session on the current build. iPhone controls, mobile interruptions, reload/reconnect and a server restart during a game remain unverified. A past connection check does not establish today’s live service or a completed release.
