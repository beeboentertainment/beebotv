Beebo for Linux (beta)

Beebo for Linux is the same desktop media server as the Windows version, packaged as an AppImage and a .deb. It is a beta that arrives with the next release, and the download link will appear on this page when that release is published.

Status: beta, coming with the next release. The download link appears here when the release is published. Until then there is nothing to download, and the install steps below are written ahead of time.

What it is

Beebo for Linux is the same desktop server as the Windows version, packaged as an AppImage and a .deb package. You point it at your own movie and show folders, and you watch on the Android app, in any web browser, or by casting to a Chromecast or Google TV. Everything else about how Beebo works is the same as on Windows.

Requirements

  • A 64-bit PC (x86-64) running a glibc-based distribution such as Ubuntu 22.04 or newer.
  • libfuse2 if you use the AppImage. The package name can differ between distributions.
  • A graphical desktop session. Beebo is a desktop app, and this beta is not built or tested for headless or Docker installs.
  • Your own movie and show files. Beebo includes no movies or shows.

How well it has been tested

This is a beta. It has been tested by an automated install and launch on Ubuntu 22.04 only. Other distributions and desktops have not been tested.

Install steps Available with the release

These steps cannot be followed yet, because the files are not published. File names below are placeholders.

  1. Option A: the .deb package (Ubuntu and Debian)

    Download the .deb file, then in a terminal in the download folder run:

    sudo apt install ./<downloaded-file>.deb

    Then start Beebo from your applications menu.

  2. Option B: the AppImage (most distributions)

    Install libfuse2 with your package manager, download the .AppImage file, and make it runnable:

    chmod +x <downloaded-file>.AppImage

    Then run it with ./<downloaded-file>.AppImage or double-click it in your file manager.

  3. Set up your library

    The first time Beebo opens, create your owner account and choose your movie and TV folders, just like on Windows. The setup guide shows the same steps for Windows.

Honest limits

  • Beta. Expect rough edges, and tell us what you find.
  • No automatic updates on Linux. You install new versions yourself.
  • Saved passwords and keys are only encrypted if your system has a keyring such as GNOME Keyring or KWallet. Without one, Beebo keeps them as plain text in its settings file.
  • The system tray icon has not been checked on Linux desktops yet.
  • Away-from-home connections have not been tested on Linux. Watching at home on your own network is the expected first use.
