Install Beebo on a Roku

A tester channel of Beebo for Roku. You install it from a computer on the same Wi-Fi, using the Roku’s own developer installer, then sign in with a code you approve on your phone.

In development This channel has not been tested on a real Roku yet. Its code was checked in a Roku simulator on a computer, not on a TV. Things may not work, and you are helping us find out what. Thank you.

The tester channel uses plain placeholder pictures for its icon and loading screen. That is expected.

Before you start

  • You need Beebo already running on a computer at your home, and your own Beebo username and password.
  • The Roku works best on the same Wi-Fi as the Beebo computer. Away from home it only works if the home router has been set up to let it in, so please test at home first.
  • You need a computer (or tablet) with a web browser on the same Wi-Fi as the Roku, with the tester file saved on it. Do not unzip it.

Download the Roku tester file (beebo-roku.zip)

Steps

  1. Go to the Roku Home screen

    Turn on the Roku and go to its Home screen.

  2. Open the developer settings

    On the Roku remote, press these buttons in order, without stopping: Home, Home, Home, Up, Up, Right, Left, Right, Left, Right.

  3. Turn on the installer

    A Developer Settings screen appears. Write down the address it shows (it starts with http:// and is followed by numbers). Choose Enable installer and restart.

  4. Accept the developer agreement

    This is Roku's own agreement for developer mode on your Roku.

  5. Make a web server password

    Make up a web server password and type it in. Write it down; you need it in step 7. The Roku restarts.

  6. Open the Roku's page on your computer

    On your computer, open the web browser and type the address from step 3 into the address bar. If you lost it: on the Roku, Settings > Network > About shows the "IP address".

  7. Sign in to the Roku's page

    A sign-in box appears. The user name is rokudev. The password is the one you made in step 5.

  8. Upload and install

    On the page that opens, choose Upload, pick the file beebo-roku.zip, then choose Install (on some Rokus the button says Install with zip).

  9. Sign in with Link a TV (the main way)

    Beebo starts on the TV by itself. Choose Find my Beebo with a code from my phone. The TV shows a code. On your phone, open Beebo, go to Settings, then Link a TV, enter the code and approve. The Roku connects to your home and shows your library.

  10. Or sign in by hand

    If the phone way does not work, or you have no phone with Beebo: if Beebo lists Beebo server at ..., choose it. If not, choose Type a server address and enter your Beebo computer's address on your Wi-Fi (the Beebo owner can tell you). Then type your Beebo username and password with the on-screen keyboard.

The channel stays on the Roku under the name "Beebo Entertainment" (marked as a developer channel). Installing a new tester file later replaces it.

If something goes wrong, tell us

Send a short message in the tester chat with:

  • Your Roku model (Settings > System > About).
  • Whether you signed in with the phone code or with username and password.
  • Which step number went wrong, and the exact words on the screen (a phone photo of the TV is perfect).
  • Whether you were at home (same Wi-Fi as the Beebo computer) or away.
  • For playback problems: the movie or show name, and whether it never started, stopped part way, or had no sound or picture.

Please do not send your password or the Roku developer password.
