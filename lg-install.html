Install Beebo on an LG TV

A tester app of Beebo for LG smart TVs (webOS). You install it on a TV in Developer Mode with LG’s free tools from a computer. Or try Beebo in the TV’s own web browser, with nothing to install.

In development The Beebo TV app has not been run on a real TV yet. It has only been tried in a desktop web browser. Expect problems, and please tell us exactly what you saw.

Before you start

  • You need Beebo already running on a computer at your home, and your own Beebo username and password.
  • The TV and the Beebo computer should be on the same home network (same Wi-Fi or router).
  • For the app: an LG TV from 2020 or newer (webOS 5 or newer), a free LG developer account, and a Windows, Mac or Linux computer with Node.js 18 or newer on the same network as the TV.
  • The Beebo owner may need to turn on Allow TV apps (Samsung/LG) to connect in the Beebo desktop app's Settings. Without it the TV app stops at "cannot connect".

The easy way: the TV's web browser (no install)

  1. Open the TV's web browser

    On the LG TV open the Web Browser app.

  2. Type your Beebo address

    Type your home's Beebo address (the Beebo owner can tell you). Use your Beebo address rather than a bare number address, so the browser trusts the connection.

  3. Sign in and play

    Sign in with your own Beebo username and password, choose a film and press play.

This works best with an LG Magic Remote (it has a pointer). With a plain arrow-key remote it is clumsy: the arrow keys do not move between posters, and the remote's Back and Play/Pause buttons are not handled by the page. Older TV browsers may not show where you are on the page or may not play every video.

The app: install in Developer Mode

Download the LG tester app (beebo-lg.ipk)

On the TV

  1. Make a free LG developer account

    Sign up at webostv.developer.lge.com.

  2. Install the Developer Mode app

    On the TV open the LG Content Store, install the Developer Mode app, open it and sign in with that account.

  3. Turn on Developer Mode

    Switch Dev Mode Status ON. The TV restarts. Open the Developer Mode app again and switch Key Server ON. Write down the IP address and the passphrase it shows.

  4. Keep Developer Mode on

    Developer Mode switches itself off after a set number of hours (the app shows the time left). Press Extend before it runs out, or the Beebo app disappears.

On the computer (same network as the TV)

  1. Install LG's tools once

    npm install -g @webos-tools/cli

  2. Add the TV

    Run ares-setup-device and add the TV: name tv, the TV's IP address from the Developer Mode app, port 9922, user prisoner.

  3. Pair with the TV

    Run ares-novacom --device tv --getkey and type the passphrase from the Developer Mode app.

  4. Install Beebo

    In the folder where you saved the file, run ares-install --device tv beebo-lg.ipk

  5. Open Beebo

    Run ares-launch --device tv tv.beebo.smarttv, or open Beebo from the TV's app list.

Then, on the TV

  1. Find your Beebo

    Choose Type my server address and type your Beebo computer's address (the Beebo owner can tell you), or Find my home with a code and approve it on your phone with Settings > Link a TV in the newest Beebo phone app.

  2. Sign in

    Sign in with your own Beebo username and password.

  3. Try it

    Move around with the arrow keys, open a film, play, pause, seek, and try subtitles, audio track, quality and Back.

If something goes wrong, tell us

Send a short message in the tester chat with:

  • Your TV brand, model and year.
  • Whether you used the web browser or the installed app, and how you signed in.
  • What worked, what did not, and the exact words on the screen (a phone photo of the TV is perfect).
  • Whether you were at home (same network as the Beebo computer) or away.

Please do not send your password.
