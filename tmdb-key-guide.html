SETUP HELP / OPTIONAL POSTERS & INFO

Give your library
its familiar faces.

Add posters, cast and descriptions to matching movies and shows. Do this once on the computer hosting your Beebo library. You can skip it and use supported local media without online artwork.

Already seeing posters? You may already have a key or saved artwork. There is no need to repeat setup. An API key is a credential for the artwork provider; it is different from your Beebo password.

Could Beebo handle this later? We are exploring funding appropriately licensed commercial metadata and artwork access so users would not need their own key. This is not available yet: provider permission, attribution and ongoing costs still need agreement. The steps below remain the current optional setup. Read what we’re exploring.

  1. Open the provider’s API settings.

    On your computer, create a TMDB account or sign into your existing account. Complete any verification it requests, then open Settings → API.

    The provider recommends a desktop browser for API registration. Its buttons and approval steps may change.

  2. Request the appropriate access.

    Read the provider’s terms and describe your intended use accurately. Use only credentials approved for that use. When available, copy either API Key (v3 auth) or API Read Access Token.

    Non-commercial API use can be free subject to attribution and the provider’s terms. Commercial use needs appropriate permission. Bringing your own key does not by itself grant commercial rights. Read the provider’s access and usage guidance.

  3. Paste it into the Beebo desktop app.

    Open Settings, find TMDB API key / token, paste the credential, then choose Save.

    For guided checking, select Easier: use the guided setup, with a Paste button. The Get posters and info section can check your key before saving it.

    Save it in the app on your host computer—not on this website or on each phone. Never send a key, password or an unredacted settings screenshot in community chat.

  4. Return to Movies or TV Shows.

    With internet access, Beebo can look up matching titles and fill in available artwork and information. Large libraries can take time. A key cannot guarantee a correct match for every filename.

    A movie title plus its year, or a show name with season and episode numbers, makes identification clearer. Check the result before accepting a match.

A little help if you get stuck.

The key was rejected.

Copy the full API key or read-access token again, without extra spaces. Do not paste your provider password or Beebo password. Use the guided check; if access remains denied, review your API account with the provider.

The key works, but artwork is missing or wrong.

Check that Beebo has found the file and can reach the internet. Allow time for lookups. Ambiguous titles, misspellings and unavailable provider artwork can leave gaps. Use the title’s match-correction controls where available in your build.

Do I need a key on every phone?

No. This guide configures the Beebo computer hosting your library. Connected clients use the information supplied by that server. A separate host computer needs its own configuration.

What leaves my computer during a lookup?

Beebo saves the credential in its desktop settings and uses it to authenticate requests to the metadata provider. Matching sends search information such as a title and year; artwork is fetched online. These lookups do not upload the movie file. This is an online service, not a promise that no information leaves your computer.
