The details behind your playback

A few controls.
A better fit for you.

Choose the picture size, soundtrack and subtitles that suit the moment. Beebo uses the source computer to prepare a compatible stream when processing is needed.

Technical information reviewed September 23, 2026. Source implementation, local checks and device validation are identified separately.

Find the controls while a video is playing

  1. Open the player’s quality or settings control.

    On supported streaming players, the gear or playback-settings panel gives access to available quality, audio and subtitle choices. Exact placement differs by device and release.

  2. Choose only what you want to change.

    Start with Auto for normal viewing, or select a smaller size when the connection struggles. Choose an audio language/commentary track or a subtitle track if the source includes one.

  3. Check the resulting playback route.

    A soundtrack or subtitle change can cause remuxing or conversion. Your original video file remains unchanged.

Downloaded/offline playback uses the file and controls available on that device. It does not ask an offline computer to create a new stream. Streaming controls and offline controls should be tested separately.

Auto, Original and smaller picture sizes

Auto

Uses Beebo’s playback decision and the current player/settings to choose a suitable route. It is not a promise that every stream continuously switches between multiple resolutions.

Original

Requests the source picture without resizing when the player and connection support it. Original 4K bitrate can be much higher than the converted profiles.

1080p, 720p or 480p

Requests a bounded output size. Lower choices reduce the configured bitrate; they ask the source computer to convert when needed. Smaller input video is not enlarged.

There is no 2160p live conversion output in the reviewed quality ladder. Compatible 4K original playback, 4K remux and reducing a 4K input are supported routes with their own conditions. See the four separate 4K capabilities.

Audio processing numbers

Night mode uses a compressor threshold of 0.07, ratio 2.5, attack 15 ms and release 250 ms, with a limiter. Measured loudness processing targets −16 LUFS, −1.5 dB true peak and loudness range 11. These are processing settings, not measured guarantees for every speaker and source.

The audio-copy policy in the live-audio module is limited to AAC, AC-3 and E-AC-3 with up to six channels. Higher-channel original passthrough is a separate path and must be tested on the actual receiver.

Set up optional subtitle search
  1. On the computer, open Settings and find Subtitle search.
  2. Use the provider/account instructions shown in that setup screen. Supply the required API credentials there.
  3. Use the connection test to check access and any reported download allowance.
  4. Search from a supported player, choose the result matching your copy and language, then verify timing.

The home computer performs the search/download for supported remote players. Downloaded subtitle files are saved beside the video, with the language in the filename. Existing subtitle files are not intentionally overwritten by the download flow.

No external provider subscription is included with Beebo. Use subtitles and media you are authorized to access. Search is optional; local subtitle playback does not require that provider account.

Owner controls for the source computer

In desktop Settings, look for Quality choices for phones, TVs and browsers and the relevant home-theater controls. Settings can differ by release and operating system.

Allow conversion

Choose whether the server can make compatible playback streams. If you turn it off, incompatible files or burned-in subtitles may no longer play on that device.

Protect capacity

Use the concurrent-conversion limit to match your computer. Default limits vary with the capacity profile and available hardware; a busy queue is not an extra paid unlock.

Optional codecs

AV1 output is an owner opt-in and is off by default. It also needs a suitable encoder and a player declaring AV1 decoding. H.264 remains the normal fallback.

Temporary files and preparing an item ahead of time

Normal on-demand streaming creates temporary pieces and clears old or idle session work. The original library file is read, not overwritten. Owner-selected preparation can warm a stream before viewing, but it is not a permanent offline copy on every device.

To watch when the source computer is off, complete a supported download to the device first and verify it offline. Read the offline viewing guide.

When something does not look or sound right

Why is a quality choice unavailable?

The source may be smaller than that size, conversion may be disabled, the chosen route may be incompatible, or the computer may be busy. Check the player’s explanation and owner settings. Trying Original only helps if the device and connection support the original file.

Why did subtitles trigger conversion?

Text subtitles can often be supplied separately. Image subtitles need to be rendered somehow; if the player cannot render them directly, they are burned into the video. That requires picture conversion and can affect HDR.

Why did surround sound become stereo?

The selected track, receiving player, connection or owner setting may require a downmix. Check the actual route and receiver input mode. A source badge or many physical speakers does not prove that a multichannel signal reached them.

Why is an HDR conversion less vivid?

Full conversion currently targets SDR. Tone mapping must fit the source and the available host filters; if a compatible method fails, fallback colors can be wrong. Record the file attributes and route for a tester report rather than marking all HDR playback as verified.

What information helps a tester reproduce this?

App version/distribution, device and operating system, original codec/resolution/audio/subtitle format, selected quality and playback path, and the exact action that caused the issue. Use original or authorized sample media and avoid exposing personal account details. Send a scoped tester report.
