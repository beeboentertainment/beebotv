A good first step

New to Beebo?

Follow the setup guide →

You bring the media. Beebo brings it together.

Beebo does not include movies or shows. Choose files you have permission to store and play, create your owner account, then connect your phone on the same Wi-Fi for the first setup.

The browser player is Available. Open the Beebo address shown by your home computer and sign in. There is no separate player to download.

Read before relying on it

What changed. What still needs a try.

See testing & progress →

These notes describe the named releases. Each feature’s tested score is on the testing evidence page. Earlier device checks do not prove a newer download.

Windows 0.1.126

Live TV recording: a new Remove from list button takes an entry off the recording list, entries beyond the 1,000-entry limit are no longer dropped when the app starts, and the limit still holds after a restart. Backup: a link or other non-file in the safety-copy folder is no longer treated as a safety copy, so restore and clean-up never follow a link outside that folder. Nothing new is deleted. Audiobooks: old library indexes re-read M4B and MP4 parts once so their covers are repaired (chapters kept); a late Library error no longer replaces a good Series view; in the browser, choosing another tab while a search is running no longer jumps back to the library list. Beebo Inbox and organizer: a double-episode file keeps both numbers in its new name (S01E01-E02); the not enough space notice clears when Windows reports the same file with different letter case; when the folder you pick is itself an Extras, Trailers or Samples folder, its videos are treated as extras. Renames only, nothing is deleted. Library and metadata: bracketed tags at the end of an episode title are removed cleanly, a show named only with a year is matched, an Extras, Samples or Trailers folder with S01E01-style bonus names is not mistaken for a show, and library search ignores every accent mark in more scripts. Converter: Convert whole show finds queued files whatever the letter case in the path. Watch Together in the browser: a room update waits until you finish typing a word with Japanese or Chinese input, and an invalid room code in the address no longer turns a remembered room into an invite. Windows only. The phone app (1.73, build 145) and Beebo Auto (1.22) are separate releases. Full list in the release history.

Testing scope: Automated checks: the full Windows desktop test suite ran on the merged changes (2,083 files); its one real failure came from a change that was then taken out of this release, and a re-run of the 289 affected files passed 289 of 289. One other test failed only from test-machine memory and passed with more memory, and one timing-sensitive test passed when run alone. Each change had a clear code review (two for protected changes), and the signed installer passed its signature, size, converter, connection-helper and language checks. The full suite was not re-run after the version-number change, and no person has installed this version or tried its in-app update yet. Windows 0.1.126 (Windows only) has had automated tests and code reviews only; no person has tried its changes or its in-app update yet.

Windows 0.1.125

Sharing with another household: you accept an invite with the share code alone and one Accept invite button, with no e-mail, password or guest box. German share-code wording uses formal Sie. Link a TV: a TV you remove loses its connection to the home PC within minutes, including profiles switched on that TV. Campsite: the owner can host a Campsite from this computer for guests on the same Wi-Fi (in development), with limits per guest device and translated screens. Users: removing a household member removes only the settings, sessions and party access of that person, keeps the settings of every other member, and refuses to remove the last owner. No videos, exports or backups are deleted. Jellyfin apps: when Live TV is switched on, Jellyfin apps can list channels and the guide and play a channel (read-only). Live TV recording: stopping, cancelling or resuming a recording keeps the parts already recorded, a lost tuner resumes, cancelled series airings are skipped, channel logos inside M3U lists show, and counts use the right plural. DLNA speakers: playback resumes after a speaker scan ages out, speakers show the track name and details, and old speakers drop off the list. Backup and restore: messages are accurate and translated, the restore preview says which items will be replaced, and the parental PIN and backup passphrase are checked without freezing the app. Watching in the browser: after a seek the subtitle for the new spot shows at once, going Back to Movies keeps your search, a podcast speed chosen while settings load is kept, phone speakers no longer flicker Out of sync, and pressing Movie Night again brings the open room forward. Smaller fixes: Up Next and Previous handle files that hold two episodes; sizes just under a unit show as the next unit and broken lengths show as zero; zh-Hant metadata uses Traditional Chinese; Remote Desktop says No picture yet when nothing arrives; asking for a title again reopens a closed request; Family Watch never shows empty extra tiles; the window keeps a 640-pixel minimum width; layout dialogs open with visible focus; the Get the app page shows dates in the page language. Separate server changes: share-code-only invites (about 7:45 AM Eastern) and the faster Link a TV removal check plus the party rejoin fix (about 8:45 AM Eastern) went live on the Beebo server on Nov 17, 2026; none of this is part of the Windows installer. Windows only. The phone app (1.73, build 145) and Beebo Auto (1.22) are separate releases. Full list in the release history.

Testing scope: Automated checks: the full Windows desktop test suite ran on the merged changes (2,082 files) and everything passed except 3 guard tests, whose two causes were fixed before this build; a re-run of the 482 affected files then passed except 2 that failed only from test-machine memory or timing and passed when run alone. Each change had a clear code review (two for protected changes), and the signed installer passed its signature, size, converter, connection-helper and language checks. The full suite was not re-run after the version-number change, and no person has installed this version or tried its in-app update yet. Windows 0.1.125 (Windows only) has had automated tests and code reviews only; no person has tried its changes or its in-app update yet.

Windows 0.1.124

Windows app engine: updated Electron to 44.9.1 with a security fix for encrypted internet connections. Sign-in: the Windows server now supports the new Keep me signed in flow and tracks kept sign-ins through normal restarts. Changing a password, ending a session or changing the owner also ends the affected kept access. An owner notice explains when a remote sign-out still needs to finish. Audiobooks in the browser: a slower answer from an earlier search can no longer replace the results for the words you have just typed. Story Studio: a story whose saved starting page is missing opens at its first available page, including after Restart. A failed page-path check now shows an error instead of disappearing silently. Library and subtitles: browser library cards have names for screen readers, episode names lose release tags without losing real hyphenated names, shows named 1923 or 1883 keep their real names, and title-review rows show the current TV match. Subtitle files have better language names and forced or hearing-impaired flags, and capital italic, bold and underline tags keep their styling. Music: volume and mute carry over to the next song and next visit in the desktop and browser players. Desktop media keys can move to the next track, empty lyrics files no longer hide embedded lyrics, short crossfaded songs are counted, and extreme ReplayGain values no longer produce an invalid volume multiplier. German Music wording uses formal Sie. Live TV guide: invalid seconds in programme times are rejected, and the next programme can be found beyond a twelve-hour gap in the cached guide. Separate server change: a limit on share-code guesses went live on the Beebo server on Nov 16, 2026, 10:59 PM Eastern (47 of 47 server tests passed before and after the change). It is not part of this Windows installer, and no real household has tried it yet. Windows only. The phone app remains a separate release; the new Android Keep me signed in flow is not in the public phone app (1.72 build 144 or 1.73 build 145). New Live TV search is outside this release. Music analysis handles damaged audio samples without propagating invalid numbers. Photos Map limits the rows shown at once when map tiles fail, while keeping located photos reachable by scrolling and keyboard. Audiobook titles and series names taken from folders keep endings such as .22 or .sf instead of treating them as file extensions. Audiobook chapter parsing handles very large chapter times safely. Extremely large video chapter times no longer crash HLS playlist creation. Long radio metadata titles keep complete Unicode characters, including emoji, at the title limit. Full list in the release history.

Testing scope: Automated checks: the full Windows desktop test suite ran on this exact source (20,849 passed, 0 failed, 84 not run, 35 to-do), two independent code reviews were clear, and the signed installer passed its signature, size, converter, connection-helper and language checks. No person has installed this version or tried its in-app update yet. Windows 0.1.124 (Windows only) has had automated tests and code reviews only; no person has tried its changes or its in-app update yet.

Full list in the release history.

Testing limit: automated tests and code review only. No person has tried this build or its in-app update yet.

Full list in the release history.

Testing limit: automated tests and code review only. No person has tried this build or its in-app update yet.

Windows 0.1.121

This release improves library and Organizer matching, browser resume and recovery after a short network drop, and photo viewer zoom, among other fixes. Full list in the release history.

Testing limit: automated tests and code review only. No person has tried this build’s changes or its in-app update yet.

Android 1.73 (build 145)

This release adds: TV remote rewind and fast-forward that match the on-screen buttons, and a Skip intro button that stays tappable; auto-next that goes on to the next episode you have; steadier connections and a correct Beebo Relay route card; music and radio that cast to a connected TV; subtitles that stay off when you turn them off; game, Campsite and Movie Night fixes; spoken names for more sliders; and lower memory use.

Not in this build: “Keep me signed in”, so updating still asks people to sign in again.

Testing limit: automated tests, independent code reviews and a check on three phones (Galaxy S24, Pixel 3, Galaxy S9+) on Nov 17, 2026; nobody has tried this build on a real TV or in a real car.

Beebo Auto 1.22 (build 23)

This release gives clearer reasons when a saved item cannot start, keeps already-loaded lists through a loss of signal, and separates work belonging to different sign-ins.

At publication: the evidence consisted of automated tests, code reviews and file checks.

Later recorded check: public Beebo Auto 1.22 (build 23), Nov 13, 2026, 8:49 PM Eastern. On a phone emulator, the settings stayed portrait at both text sizes and an empty picture-in-picture window opened and returned: 19 checks passed, 0 failed and 6 were not run.

No real-phone or car-head-unit test is recorded for this release. Active passenger media, car controls, maps ducking and driving were not tested.
