A good first step

New to Beebo?

Follow the setup guide →

You bring the media. Beebo brings it together.

Beebo does not include movies or shows. Choose files you have permission to store and play, create your owner account, then connect your phone on the same Wi-Fi for the first setup.

Prefer a browser?

The browser player is Available. Open the Beebo address shown by your home computer and sign in. There is no separate player to download.

Windows 0.1.141

Shared with you: opening a library that another home shared with you no longer ends on the sign-in page of that home ("Your username / Your password"). If the shared page tries to reload itself without its pass, Beebo now closes that window instead, so pressing Open again starts fresh. Nothing on the other home changes. Windows only. The phone app and Beebo Auto are separate releases. Full list in the release history.

Windows 0.1.140

Live TV: a channel whose source ends by itself (a short clip, or an internet TV stream that drops) now plays to its end and stops cleanly. Before, phones could freeze a few seconds in, and the clip could start again from the beginning. Films shared with this home (new, OFF unless you turn it on): More > Shared with you has a new setting, "Show films shared with this home in my Films and TV lists". When the owner turns it on, this PC connects to each home that shared its library with you and adds their films and shows to the owner's Films and TV lists in the phone and TV apps. Only the owner's profile sees them. Profiles with parental limits never see shared films. Playing a shared film from these lists is not built yet, and this window and the browser pages do not show them yet, so leave the setting off unless you are trying it out. Kitchen announcements: a phone, TV or browser that opens Beebo on the home Wi-Fi while a message is still inside its 15 seconds now shows it, only for the seconds it has left. A message already shown is not shown again. The note after sending says plainly who can get announcements: only screens with Beebo open on the same home Wi-Fi as this computer. Beebo Relay in Settings > Away from home: the notices that say why Beebo Relay cannot be used, that Beebo will ask again automatically, or that Beebo Relay could not be turned off are now translated into German, Spanish, French, Italian and Brazilian Portuguese. Sidebar: the Converted count now counts a finished conversion only while both the new copy and the original are still on disk. If you removed one of them yourself, it drops out of the count. Nothing is deleted. Music: picking an album while a mix is still starting now frees that mix's tile, and the Albums list fills in when a library scan finishes. Windows only. The phone app and Beebo Auto are separate releases. Full list in the release history.

Testing scope: Automated checks: the full Windows desktop test suite was run on the release source (2,176 test files, 22,252 tests): 22,106 passed and 0 failed; 109 tests in 34 files were skipped, so they were not run (mostly checks that need Linux, file links, an optional browser package or an opt-in switch), and 37 are marked as future work. Starting up: if another program is using Beebo's port, Beebo now keeps trying once a minute instead of giving up after about 25 seconds. After the PC wakes from sleep, Beebo checks that its media server is still running and starts it again if needed. The "start before sign-in" task now runs at normal priority, and the first screen unlock after Beebo starts no longer repeats every network check. Uninstalling Beebo now also removes its "Start with Windows" entry. Updates keep it. Reliability: a long run of repeated errors no longer makes Beebo slower and slower. Beebo's log file can no longer grow without limit when Windows keeps it locked, and lines lost to a full disk are now counted. Browser player at home: if the home computer goes to sleep or Beebo restarts during a film, the player now says it is reconnecting and carries on from the same spot when the computer is back, instead of saying the video format cannot play. German Photos text now uses the polite form (Sie). Phone photo backup and Space Saver: a backup that picks up where it stopped is no longer refused as "PC disk full" when most of the file is already on the PC, and a phone that asks again while the PC is still finishing a big file no longer sends the whole file again. A Space Saver folder can now show more than its newest 1,500 photos, an unplugged Space Saver drive now says the folder is not available instead of "No backups yet", and a thumbnail that failed half-way is no longer kept broken. Nothing here deletes or moves a photo or video. Users: renaming a person now follows the same name rules as adding one, and a blank or refused name says why it was not saved. The Users tab no longer goes blank, and View stats no longer stops working, when the answer from Beebo is not what it expects. The seat sentence now waits for the real seat limit instead of first showing "up to 6". Not switched on yet: fixes for Live Rooms (someone who reconnects shows as here again, clearer messages, turning the camera or microphone on later now asks for it) and for tournaments (a wrong number of players gives an error instead of a crash, ties go to the player with fewer losses, a refused change leaves the result untouched).
