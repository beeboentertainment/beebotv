THE LATEST FROM BEEBO

Beebo downloads and versioned release notes.

Beebo for Windows 0.1.82 and the Android test build 1.51-tester15 came out on October 7, 2026. This is a small release: it adds safer backup restore, a few fixes and some accessibility touches. Beebo Auto 1.18 is unchanged. Windows 0.1.81, tester14 and Auto 1.18 came out earlier the same day, and 0.1.80, tester13 and Auto 1.17 the day before. What’s new and what’s tested says what was tried on real devices and what was not. Earlier releases are described further down.

Behind the scenes, October 8, 2026

Beebo Entertainment is now a company. On October 8, 2026, Beebo Entertainment Inc. was incorporated in Ontario, Canada (Ontario Corporation Number 1001772318). Beebo itself works the same as before.

In progress Signed Windows installer. Today we finished setting up code signing for the Windows installer. Microsoft checked the publisher’s identity, and a test build of the installer came out digitally signed and passed Windows’ own signature check. The Windows version you can download right now (0.1.82) is not signed yet, so Windows may still warn the first time you run it. Our next Windows release is planned to be signed, which lets Windows show who published it. A new publisher can still see a short warning at first, until Windows learns to trust it. For now the signer shows as an individual publisher, not the new company; we plan to move it to the company later.

In progress Better video converter. We want Beebo’s built-in video converter to be as good as the big media servers’, and to stay fully legal. Today we emailed the companies that license the video-encoding technology to ask what a licence would involve and cost. We have no answer yet, and nothing changes in the app because of this email. We will say here what we decide.

What is new in Windows 0.1.82

Beta Released Oct 7, 2026, 11:30 AM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time you run it. A small release: the larger Household Library, walkie-talkie, Portrait Party and library-sharing work and several risky fixes are still in review and are not in this build.

  • Backups. Restoring a backup is safer: odd names hidden in a backup file can no longer slip into your settings.
  • Sign-in. Sign-in lock-outs and two-step sign-in cope with unusual saved data. The admin page checks the owner PIN exactly as typed.
  • Settings. Settings refuse a value of the wrong kind before saving it.
  • Photos and collections. Photos ignore impossible time-zone offsets. Collections list a repeated film once, and “Matrix, The” files next to “The Matrix”.
  • Watch Together. Leaving a room no longer counts against your open-room limit.
  • Internet radio. Playlists with relative entries or spaces now play.
  • Chromecast. A TV that also says Android TV gets the Chromecast settings.
  • What’s new date. The date shown on the What’s new screen now comes from the build.

Tested: the full desktop test run of the combined code passed 1,001 of 1,002 test files. The one failure, a guard test about a web address named in a comment, was fixed and then passed 6 of 6. The packaged Windows app starts and answers. Not tested: the installer on a real Windows PC (installing over an older version). Details: what’s tested.

What is new in Windows 0.1.81

Beta Released Oct 7, 2026, 2:01 AM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time you run it. Built from commit 2768a3a01.

  • Security. More security fixes from our own reviews. We keep the details private. Backup restore now keeps the people who exist only on this PC and says which parts it could not restore. Quick Connect codes only work for the person who first approved them.
  • Photos. A copy of a photo that leaves your PC now also drops a second, hidden picture that some JPEG files carry, because it could hold its own location details.
  • Parental controls. Daily screen-time limits count the repeated hour when the clocks go back. A rating limit that cannot be read is treated as strict, and the editor lets you clear it.
  • Organizer. You can send files to a network drive (NAS). Beebo tests the drive first, checks every copy and keeps the original if anything fails.
  • Space Saver (Beta). A file counts as backed up only when your computer holds an identical copy, checked by its contents. Different files with the same name are kept as numbered copies and never overwrite each other.
  • TV, music and Live TV. Linked show folders, files that hold several episodes and four-digit episode numbers are understood. A damaged music index no longer takes the library down. Live TV (Beta) recordings with names Windows reserves are saved under a safe name.
  • Accessibility. New choices for large buttons, high contrast and a captions default. The BeeboSchool, Audiobooks and Watch Together pages respect reduced motion.
  • Plainer messages. Many screens show plain sentences instead of error codes, in six languages. The new translations were made with a machine’s help and a native speaker has not read them yet.
  • Installer and updater. Uninstalling removes the start-at-boot task. The updater checks free disk space and warns before installing while Beebo is busy.
  • Camp Mode (Beta). The Beebo Wi-Fi is switched off again when the guest server cannot start or stops. War, Go Fish and Dominoes refuse a wrong number of players.
  • In development, off by default. Household Library, Channel Surfer, Remote Desktop notices, online games, Trip Journal links and guest clips, walkie-talkie from anywhere and Story Studio. Portrait Party is Planned and not switched on.

Not tested on real devices: almost all of this was checked by automatic tests only and nothing has been tried by a person on this exact release build. Not tried yet: the clock-change night for screen time, the network-drive organizer on a real NAS, Space Saver with a real phone, a screen reader for the accessibility choices, and installing over an older version. Details: what’s tested.

What is new in Android 1.51-tester14 (test build)

Beta Built Oct 7, 2026, 2:03 AM Eastern (build 64). A test build you install yourself over your existing Beebo app to keep its settings. It is not on Google Play.

  • Accessibility. Large controls, a “prefer captions” choice, spoken connection status and one TalkBack stop per label-and-switch row.
  • In development, off by default. Household Library, Trip Journal links and guest clips, and walkie-talkie from anywhere. Portrait Party is Planned and not wired to a menu.

Not tested yet: all of this was checked by automatic tests only. Nothing has been tried on a phone with this exact tester14 build: Space Saver with a real folder, Wi-Fi sleep and wake while casting, Trip Journal and Camp Mode with real phones, voice search and TalkBack. Details: what’s tested.

What is new in Windows 0.1.80

Beta Released Oct 6, 2026, 11:17 AM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time you run it. Built from commit 08ad47f58.

  • Security. We fixed several security problems found in our own reviews. We keep the details private.
  • Secure home sign-in. Home-network sign-in now has its own secure certificate that the phone app remembers. The pairing QR code in Settings carries it too.
  • Parental controls. A stricter rating limit or a blocked title now stops a film that is already playing. Family viewing turned on mid-film starts with the next film, not the one playing.
  • Watch Together, Movie Night and Phone speakers now say why someone had to leave.
  • BeeboSchool. Removing a child erases all of that child’s data, and uploads are safer.
  • Downloads and playback. Downloads only offer sizes that are really smaller than the original. Subtitles from a separate .srt or .vtt file can be burnt into the picture. Settings › Playback lists the streaming copies Beebo kept, with a Remove button. Rewind and seek are faster.
  • Movies and posters. The Movies page loads faster on large libraries, and posters show again when Beebo runs on a different port.
  • Screens and accessibility. Better contrast, TV-remote support in the web player and library pages, and an accessibility pass on the server’s own web pages.
  • Live TV. You can add your own playlist without a tuner.
  • Shared movie-info key. Movie info through Beebo’s shared key works only for accounts the owner has approved. No account is approved yet, so your own TMDB key is still the way to get info.

Our servers were updated at the same time; there is nothing to install for that part. Not tested on real devices: most of these changes were checked by automatic tests only and have not been tried on this exact release build. Details: what’s tested.

What is new in Windows 0.1.77

Beta Released Oct 4, 2026, 3:40:03 AM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time you run it. Built from commit 8443685d (Oct 4, 2026, 3:32 AM Eastern).

  • Watch along from a phone that is streaming, not downloaded. When a phone hosting Campsite streams a film from this computer and shares it with guests (“stream once”), this computer now prepares that shared copy at full speed so guests are not kept waiting. Ordinary single viewers are unchanged.
  • BeeboSchool report PIN. Only an administrator can set the first report PIN, so a child profile can no longer set a PIN the parents do not know. Changing an existing PIN still needs the current one.
  • The own-relay screen tells you when a save fails. Saving the analytics setting or changing the reset day now shows a plain message if it fails, instead of failing silently.
  • Library sharing invitations refuse hidden characters. A guest e-mail address with hidden control characters is refused.
  • Phone backups and trip links remember files more reliably. A file you already sent is no longer forgotten when the phone asks with a malformed size.
  • Translations. The relay backup wording is updated in German, Spanish, French, Italian and Portuguese (Brazil).
  • Groundwork for features that are not switched on yet. This version contains the home-computer side of a 480p Beebo Relay fallback (with an automatic restart at 480p in the web player) and of Trip Journal links that work away from home. Both are switched off and do nothing until they are tested and turned on.

Not tested on real devices: the switched-off features above. Stream once was tested with two real phones (one host, one guest) on the same home Wi-Fi.

What is new in Windows 0.1.76

Beta Released Oct 3, 2026, 4:01:15 PM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time you run it. Built from commit 52119923 (Oct 3, 2026, 2:10 PM Eastern).

  • Sign-in is safer against guessing. One password attempt is checked at a time per address and per account, so many wrong guesses sent at once can no longer slip past the lockout. The same now applies to deleting your account, changing your viewing privacy, reset codes and two-factor steps. Your home network is exempt from the shared lockout, and one person’s lockout no longer blocks everyone else.
  • Sign-in no longer freezes the server. Checking passwords and codes no longer stops everything else, so streaming stays smooth while someone signs in. Existing passwords keep working.
  • A change during sign-in is respected. If a password was changed, an account revoked or two-factor switched on at the very moment someone was signing in, that sign-in is now refused.
  • Saved keys and passwords stay hidden. The TMDB key, your email app password, notes and the OpenSubtitles key are no longer sent to the app’s screens in readable form. Settings shows Saved, with Replace and Remove. The notes field and the DuckDNS token are now stored encrypted on disk too.
  • Away-from-home passes say who they belong to. A paired TV gets a TV’s reach: it can play your library but can no longer open admin, account, API key or Remote Desktop pages, and a pass that does not say who it belongs to is refused. This needs the matching Beebo server update, which is being rolled out first.
  • Remote Desktop is stricter. It refuses to start while Beebo runs as administrator, cannot travel over Beebo Relay, and a wider set of proxy headers is refused. Remote Desktop is still in development and off by default.
  • Safer file choices. Own ffmpeg, the nightly backup folder and Live TV guide and playlist files must be picked in Beebo’s own file box, and network paths are refused. Upload file names with hidden stream parts or Windows device names are refused.
  • Safer connections for guides and playlists. A private guide address you approve can no longer redirect Beebo to another address on your network.
  • Space Saver keeps accounts apart. Two accounts whose names look alike can no longer end up in the same folder. Nothing is moved or deleted.
  • Space Saver backups work again. Files the phone sent at exactly their stated size were being refused. Photo backup and Trip Journal links also no longer forget a file you already sent when the phone asks with a wrong size.
  • Pages load more safely. The library, music, photos, playlists, appearance, account and sign-in pages now carry a stricter content security policy.
  • Fewer screens get stuck. Movies, TV Shows, Music, Podcasts, Audiobooks, Playlists, Requests, Movie Details, Playback settings, the Migration wizard and several others now show a message instead of staying on Loading or failing silently. Around 80 more screens were checked, including Settings, Live TV, Parental controls, Upload, Library sharing, Cinema, Notifications, Add-ons, Backup, Trailers and the mini player: a failed save or load shows a plain message, choices you change now stick, and refused actions show words instead of raw codes. A late answer no longer starts a video after you press Back in Surprise me.
  • The Open buttons on Home work. On the default Home look, Open on Continue Watching and on the Fresh in Movies and Fresh in Shows rows now opens History, Movies and TV Shows. Before, they opened nothing.
  • Pack for a trip shows size and time up front. The planner shows an estimate of space and time before you start downloading.
  • Smoother streaming and a faster database. Video pieces are streamed from disk when no speed cap applies, and a stalled player now stops its keep-alive timer. On some Windows setups, a person with no ratings or favourites stayed on the older data file instead of the faster database; that is fixed and nothing was lost.
  • Logs hold less. Logs and the email log no longer keep tokens, addresses or subject lines.
  • Connection Doctor’s firewall fix matches the installer. It now adds the same rule the installer does, limited to Beebo itself.
  • Music fixes. Pressing Stop while a radio mix was loading no longer starts it again. The relay button now says it is on as a backup.
  • Asks before removing things. Removing a library request or a title, and clearing items in History, Dashboard, Playlists, Podcasts, Radio and Live TV, now asks you to confirm first.
  • Easier to use. With reduce motion on, lists and maps no longer scroll smoothly; more buttons are big enough to tap easily; the Watch Together panel in the player has clearer wording in all six languages.

Not tested on real devices: Remote Desktop on a real screen, the new content security policy in the packaged app on other PCs, and the new sign-in queue under heavy real traffic.

What is new in Windows 0.1.61

Beta Released Sep 23, 2026, 1:13:58 PM Eastern. Windows only; not code-signed, so SmartScreen may warn the first time. Beebo updates itself from 0.1.60 or older; you can also download it above.

  • Watching through Beebo Relay no longer stops when Beebo’s service has a brief hiccup. The home PC keeps the video going for up to 90 seconds and asks again a few seconds later instead of cutting the stream. Together with the fix that went live on Beebo’s own service on Sep 23 (see 0.1.60 below), this closes the “video stopped about ten minutes in” problem found in this week’s security review. Direct connections and your own relay were never affected.
  • AV1 conversion only when you allow it. A conversion to AV1 now starts only when you have switched AV1 on in Settings and the watching device can play it — the same rule the player already used when it planned a stream. Before, a device could ask for AV1 on its own, which could start a heavy conversion on your PC without your say-so.

What is new in Windows 0.1.60

Beta Released Sep 23, 2026, 9:03 AM Eastern.

  • Household size raised to 15 people in total (owner plus paid extra seats), up from 12, matching the household size other services offer. Six people are included; extra seats are a paid add-on that is not on sale yet.
  • Six ready-made layout styles you can pick in one click in Appearance settings (Showcase, Adaptive Rail, Focus View, Poster Canvas, Quiet Library, Shelf Workshop), instead of only building your own.
  • Private viewing history needs a working recovery email first. Turning it on now checks a real, unique recovery email is on file and sends a confirmation to prove delivery works, so nobody can lock themselves out with no way back in.
  • Behind-the-scenes account, subscription and connection-security fixes from an independent review of Beebo’s sign-in service. Those live on Beebo’s service and did not need an app update; they are listed here for completeness. A second round of fixes from the Sep 23 full audit (a relay lease that expired ten minutes in, Stripe events arriving out of order, lost webhook deliveries) went live on the service the same day.

Earlier releases

The sections below describe changes from earlier versions (Windows 0.1.56 and Android 1.37).

Away Play: join a home-hosted game from anywhere

Home Game Server can now be reached the same way Beebo video already works away from home: a direct connection is tried first, falling back automatically to Beebo Relay if needed. Household members and invited friends can use supported home-hosted game-server connections. Actual reachability, firewall configuration and relay capacity must be tested; this is not a guarantee that every network works without setup.

Earlier away-from-home plan announcement

This archived announcement described quality-based tiers. It is superseded by the current proposed plan information: managed-service billing and limits are awaiting confirmation. An old release note is not an active subscription offer. Owner-operated playback and Beebo-managed connectivity are different services.

More reliable away-from-home connections

Fixed connections freezing for up to a minute after a network change (switching from Wi-Fi to mobile data, or a drop and reconnect), and fast-forwarding/seeking taking far too long to catch up while away from home. A new password now works away from home immediately, and choosing "Beebo Relay only" actually turns the relay on right away.

Know how your phone is connected

The Android connection banner now follows the active connection when its route changes. It identifies Beebo Relay or Cloudflare Relay when that provider can be confirmed. While checking, it says so instead of assuming a direct connection.

A friend’s Wi-Fi or a cellular connection can still connect directly to your home over the internet. The banner reports the actual connection route, not just which network your phone has joined.

Beebo Relay’s encrypted port 443 connection has also been repaired on our server. An enabled relay and a completed away-from-home phone test are now described separately in desktop setup.

A desktop that is easier to find your way around

  • Get Started: setup panels sit side by side on wider screens and stack on smaller windows.
  • Phone Backups: a clearer label for your backed-up phone photos and videos.
  • Video Playlists: makes it clear these collections contain movies and TV episodes.
  • Upload history: remove one entry or clear the displayed history without deleting the video files.
  • Log out: a dedicated button beneath the version and update information.
  • Away access: enable it for all approved users and choose a default for new users. Pending and revoked accounts still need approval; individual restrictions are respected.

Dice that roll on the board

In Ludo, Snakes and Ladders, and Five Dice, three-dimensional dice tumble over the board or dice tray, then settle on the host’s result. Guests see the same result on their own phones.

  • In Five Dice, tap a die to keep it. Kept dice stay still while the others roll.
  • Rolls stay close to the board as you scroll, and reduced-motion settings skip the tumbling.
  • A failed connection does not display an invented result. You can retry the action.

A fresh look across your games

  • New illustrations for 38 shared games and four solo games.
  • Detailed chess pieces, wooden boards, glossy counters, ivory dominoes and a matching card deck.
  • Drop Four counters drop into place. Cards and dominoes lift when selected.
  • Refreshed Patience, Five Letters, Number Grid and Hidden Mines graphics.

Play with friends on their own phones

  1. Update Beebo on the host phone.
  2. Open Other → Games → Play with guests and start your campsite session.
  3. Guests join the same hotspot or local Wi-Fi, scan the guest QR code and enter their names.
  4. Everyone opens Games, chooses the same game, and the leader starts the round.

After updating, restart Campsite Mode and have guests reload their game page. The artwork is included in the app, so guests do not need an internet connection to fetch it.
