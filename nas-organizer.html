Organize files on a NAS In development

Choose a writable network folder as a destination for the desktop media organizer, then review the plan before it writes anything.

In development. This feature page separates the work in the code from what has been checked on real equipment. Read the untested section before trying it.

Your destination, your choice

The optional organizer searches only the folders or drives you choose. You can select videos, photos or both, choose a writable destination and review where each file would go. It does not search automatically or change your library folders for you.

Copy first, review before moving

Copy is the default. Move is a separate explicit choice. The plan shows destinations, warnings and space estimates before confirmation. Copies are verified with a digital fingerprint, and a move checks the original and the copy again before removing the original.

Network-folder limits

The code skips protected or linked paths and checks for changed files and name collisions. A network drive can behave differently from a local disk. A remaining timing gap exists if another program deliberately replaces a reserved destination name just as the organizer finishes publishing it. Use a disposable Copy trial before trusting a new NAS destination; these checks are not an absolute guarantee against another program changing files.

What is not tested yet

Temporary-file tests cover organizer safeguards, but a real NAS model, interrupted network share and the complete reviewed screen flow have not been established by this page. Windows access permissions and enough space still matter. Running Beebo on a NAS is a different feature from using a NAS folder as this organizer’s destination.
