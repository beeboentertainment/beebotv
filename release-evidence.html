What the badges and numbers mean

  • ✔Confirmed working on real devices Used only when the Real device check, the Real-world check and the Ready to call Available check have all passed, with no code item open. It means all listed checks passed. It does not mean bug-free.
  • ◐Code complete — needs more real-world testing to confirm The code is built, its automated tests pass and no code item is open, but at least one of the real-device, real-world or ready checks has not passed yet.
  • ⚙︎Code still being finished At least one code item is still open (building, fixing or an independent review), or the Built or Automated tests check has not passed.

The first number, “Code”: the share of the two code checks (Built and Automated tests) that passed. A feature reads “Code 100%” only when both passed and no code item is still open for it. The second number, “Tested on real devices”: the share of the three real-world checks that passed. The percentages measure our own checklist, not that nothing can go wrong. We do not call anything 100% working.
