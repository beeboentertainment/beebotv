What the status words mean

Current downloads: Windows 0.1.106, published Oct 28, 2026, 1:26 AM Eastern; Android 1.51-tester58 (build 108), published Oct 27, 2026, 2:59 PM Eastern; Beebo Auto 1.21 (build 22), published Oct 27, 2026, 2:59 PM Eastern.

Device checks: Windows 0.1.103 was installed over 0.1.102 on one real second-household PC (it updated by itself in 54 seconds) and 0.1.104 updated by itself in 41 seconds. Windows 0.1.105 has had automated tests and code reviews only; its in-app update has not yet been tried by a person. Windows 0.1.106 has had automated tests and code reviews, and one tester working alone (Nick away) has since updated a PC to it and re-tried most of its changes; no one else has tried it yet. Android tester58 and Beebo Auto 1.21 have had automated tests and code reviews only; nobody has tried them on a phone, a TV or in a car yet. Beebo Auto 1.20 had one first look in a real car (Oct 27, 2026) and still needs fuller real-car checks. See the dated test record. Checks made after publishing will be recorded in the release evidence. Earlier device results remain historical and belong to the builds they name. Feature percentages come from the release evidence page and change only when a dated check is recorded. Read the release notes and limits.

Start here, Quick answers and similar labels describe the guide status last recorded for Beebo for Windows 0.1.88 and Android 1.51-tester23. Available means it is in a current download and you can use it today. Beta means you can try it now, but it is new, some parts may not work, and its page says what is untested on real equipment. In development means it is being built or switched off, with no date, and Planned means it is not built yet. What’s new and what’s tested lists the newest real-device results.
