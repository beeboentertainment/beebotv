Beebo on Samsung and LG smart TVs

LG has an in-development tester app you can install. The Samsung app is in development and has no install file yet, but you can try the TV’s web browser. Neither has been tested on a real TV yet. This page says what to expect and what you can use today.

Testers wanted — posted Sep 21, 2026, 4:46 PM Eastern. We need testers with Samsung and LG TVs. Sign up to test Samsung and LG →

In development LG: a tester app for LG TVs in Developer Mode, tried in a desktop browser only, not tested on a real TV yet. Download the tester file · Install guide

In development Samsung: no install file yet. Try: open your Beebo address in the TV's web browser. Not tested on a real TV yet; it works best with a pointer remote.

What we are building

Beebo apps for Samsung smart TVs (which run Tizen) and LG smart TVs (which run webOS). Both kinds of TV run web-based apps, so we plan to build the TV screens once and package them for each brand. Each brand has its own app store and its own review, so each would be released separately.

What you would need

  • A Beebo server running on a Windows 10 or 11 PC.
  • A Samsung or LG smart TV. Which TV years and models will work has not been decided.

How it is expected to work

  • The app would show your library and play it from your PC. It includes no movies or shows.
  • It has to be made easy to use with a TV remote: moving around the library and controlling playback without a mouse or touch screen.

Honest limits

  • Neither is a finished app. The LG tester app and the web browser way have not been tested on a real TV, and Samsung has no install file yet. There are no store release dates.
  • Each app has to pass its store’s review before it can be shared widely. Samsung and LG each have their own process and timeline.
  • Which connection options the TV apps will support at launch has not been decided.
  • The details above describe what we expect, and may change.

What works today on a TV

If your TV has Chromecast built in, or you plug in a Chromecast or Google TV, you can cast from the Android app, and your phone becomes the remote. Casting works when your phone and the TV are on the same Wi-Fi. Beebo also runs on Android TV and Google TV through the Android app.

Want to know when a Samsung or LG TV app is in the store? Email us to be notified. This is a plain email to testers@beeboentertainment.com: there is no form and no sign-up. Tell us which device you use and we will write back when there is news.
