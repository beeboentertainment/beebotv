Household Library In development

A shared view of the movie and TV folders on your household’s computers, with each computer approved by the owner.

In development. This feature page separates the work in the code from what has been checked on real equipment. Read the untested section before trying it.

One household, several computers

The early work builds a catalogue from folders you choose. It records which computer holds each title and distinguishes a saved listing from a computer that is actually online. This is separate from sharing your library with another household.

Approval comes first

Another computer must belong to the same household and have the owner’s approval before its titles can appear. Private and application folders are excluded. Adding a folder is an explicit choice; catalogue scanning reads file information and does not move your media.

The current limit

The catalogue and approval screens have local test coverage, but the everyday app still needs the connection between the screens and the household service. Multi-computer playback is not complete. An offline title listing is not a promise that the file can play.

What is not tested yet

The complete owner-approval, two-computer connection and playback journey has not been established on real household equipment. This page describes development work, not a release announcement or a switch you can rely on in the current download.
