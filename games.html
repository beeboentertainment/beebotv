Where you play

Games run inside Beebo. For group play, the host starts Campsite Mode and guests join on their own phones through the host’s browser link. A guest does not need a Beebo account.

This page is a game catalogue and how-to guide. It does not run standalone website game demos. The four independent solo games run on the host phone, not in a guest browser.

The list is checked against the current app registrations. A listed game is not a claim that every device, opponent mode or tournament has been tested.

Local host-phone option and campsite play

One host. Two joining steps. Your own screen.

  1. The host starts Campsite Mode and shows the hotspot joining code when using a supported phone hotspot.
  2. Guests connect to the host’s local Wi-Fi, then scan the browser code or open the shown address.
  3. Choose a nickname, or use the offered guest name. The host opens a game; each guest plays from their own screen.

Prepared local games and downloaded videos can be shared without internet while everyone remains connected to the host’s local network. Hotspot range, the host phone’s battery and its supported guest count still matter. Internet-only content and online services remain separate.
